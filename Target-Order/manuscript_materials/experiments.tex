\section{Reproducible Experiments}
\label{sec:experiments}
\subsection{Data, Sampling, and Estimands}
\label{subsec:experimental-settings}
This section replaces the earlier unreproduced tables and plots with a
new, independently executable study on CHILD and ALARM. It does not
claim to recover the original random-CPT library or historical timings.
We use the publicly distributed BIF structures and CPTs from the
bnlearn Bayesian Network Repository \citep{bnlearnrepository}.
CHILD has 20 nodes and 25 arcs; ALARM has 37 nodes and 46 arcs.
We retain one supplied parameterization per network, including its
zero CPT entries. Decimal-rounding row normalization, original compressed
files, exported CPT arrays, retrieval information, and SHA-256 checksums
are included in the accompanying \texttt{data/} and
\texttt{results/environment.json}.

For CHILD we condition on
$\mathrm{ChestXray}=\mathrm{Normal}$ and
$\mathrm{HypoxiaInO2}=\mathrm{Mild}$.
The query is the joint distribution of $(\mathrm{Disease},\mathrm{Sick})$;
the scalar event is $(\mathrm{TGA},\mathrm{yes})$.
For ALARM we condition on
$\mathrm{PRESS}=\mathrm{NORMAL}$ and
$\mathrm{EXPCO2}=\mathrm{NORMAL}$.
The query is the joint distribution of
$(\mathrm{INTUBATION},\mathrm{DISCONNECT},\mathrm{MINVOLSET})$,
with scalar event $(\mathrm{ONESIDED},\mathrm{TRUE},\mathrm{NORMAL})$.
These are the names in the released BIF files, not abbreviations
assumed to exist in a different parameter library.
The evidence probabilities are approximately $0.02331$ and $0.005901$,
respectively; evidence is not treated as a free source of samples.

The master seed is 20261007. Each network receives 100 randomized Kahn
topological orders, using uniform selection among the currently eligible
vertices and deterministic sorting of that eligible list before selection.
This is not uniform sampling over the set of all topological orders.
We save the full orders and restricted orders instead of relying solely
on a seed to describe the candidate set.

We use 20 independent repetitions per network. Each repetition contains
500 pilot observations, a disjoint fitting pool of 5000 observations,
and a disjoint validation sample of 1000 observations.
The fitting sizes are $n\in\{100,1000,5000\}$, using nested prefixes
of that repetition's fitting pool. Observations are generated by exact
ancestral sampling followed by rejection on the evidence event.
The accepted observations, proposal counts, state encodings, seeds,
and sample-splitting convention are saved. All orders share the same
observations within a repetition, so comparisons are paired;
neither candidate orders nor sample-size points are independent repetitions.

Every fitted model uses a BDeu posterior mean with $\mathrm{ISS}=10$.
We compute exact conditional family marginals and target marginals by
variable elimination with deterministic minimum-result-factor-size
ordering. Thus there is no additional Monte Carlo error in the reported
query truth or KL evaluation. For an exact conditional graph,
KL is evaluated by the local decomposition; for the induced-subgraph
baseline, cross entropy is evaluated using its true family marginals
and the conditional entropy obtained from an exact conditional graph.
KL is measured in nats. Scalar-event RMSE is
$\{\frac1{20}\sum_{j=1}^{20}(\widehat p_j-p)^2\}^{1/2}$;
it need not rank methods in the same order as whole-distribution KL.

\paragraph{Operational baselines.}
The full-joint reference computes
\[
P^C(X_T=t)=
\frac{\sum_{x_{R\setminus T}}\prod_{v\in V}
 p_v(x_v\mid x_{\pa_G(v)})\big|_{x_T=t,x_C}}
{\sum_{x_R}\prod_{v\in V}
 p_v(x_v\mid x_{\pa_G(v)})\big|_{x_C}}.
\]
The conditional-graph method uses FGCR and estimates each resulting CPT
from conditional observations. The induced-subgraph method uses $G[R]$
and estimates its CPTs from exactly the same conditional observations.
Under known CPTs, both graph-based methods use true conditional family
probabilities, not slices copied blindly from the original CPTs.
We do not compare a joint-model learner given unconditional data with a
conditional learner given selected data and call that a like-for-like
sample comparison.

\subsection{Structural Checks and Construction Cost}
\label{subsec:structural-consistency-experiment}
For each sampled order, an independent ancestral-moralization
$d$-separation oracle constructs both the full ordered MDI map and the
ordered conditional MDI map. Both agree exactly with FGCR in every case.
This verifies the implemented constructor against the defining
independence model, not against an unprovided ROS implementation.
The FGCR--ROS equality remains a theorem under the stated common-order
conditions, but no ROS timing claim is made by these experiments.

All 100 full orders and all 100 remaining-node orders are distinct in
each network, but they produce only 5 distinct CHILD graphs and
50 distinct ALARM graphs. We therefore fit once per distinct graph
and map the result back to each sampled order. Deduplication avoids
counting identical graph fits as independent evidence.
The parameter dimensions range from 202 to 310 in CHILD and from
445 to 673 in ALARM. With known CPTs, all constructed target marginals
agree with the full-joint reference to below $2\times10^{-16}$ in
maximum coordinate error.

Construction timing uses a warm-up followed by ten individual
\texttt{perf\_counter\_ns} calls per order; Table~\ref{tab:new-time}
summarizes the distribution of per-order medians. Topological-order
generation, oracle verification, data reading, CPT fitting, and inference
are excluded from this descriptive constructor timing. The Python
implementation maintains current-position maps and parent hash sets.
The run used Python 3.12.14, NumPy 2.3.5, and Windows 11 on an
Intel64 Family 6 Model 186 processor; the full runtime description and
raw individual timings are recorded. Timings at this scale are noisy
and machine-specific. They do not establish a strict speed advantage
over another constructor.

\subsection{Order Sensitivity and Selection}
\label{subsec:order-selection-experiment}
We compare six deployable choices: the smallest-dimension candidate;
a random sampled order; the pilot-quantile heuristic; held-out log-loss
selection; minimum empirical-certificate selection; and the induced
subgraph baseline. Pilot scoring uses 10th percentiles of positive
observed parent-cell frequencies and fitted CPT entries, with the
dimension and swap penalties set to zero before running the study.
The minimum-dimension baseline breaks ties by the first sampled order.
The held-out selector minimizes validation log loss over distinct graphs;
the selected fit is not retrained on validation observations.
Certificate selection applies Theorem~\ref{thm:empirical-certificate}
with $\delta/K$ for $K$ distinct candidate graphs before minimizing.
An additional true-KL oracle is saved only as a diagnostic, not used
by any deployable selector.

The results do not uniformly favor the proposed pilot heuristic or
validation selection. At $n=5000$, the minimum-dimension candidate has
mean joint KL approximately $0.02061$ on CHILD and $0.03319$ on ALARM.
The ALARM pilot heuristic has mean KL approximately $0.03619$,
whereas the held-out choice has mean KL approximately $0.03437$.
Thus the validation guarantee is not a claim of empirical domination
of simple dimension minimization. Random-order mean KL is larger in
these runs, but the study does not establish a general ranking.

For the specified CHILD query, all sampled orders and the induced
subgraph have the same RMSE to numerical precision. This query is
insensitive to the omitted dependencies even though their joint
distributions have different KL risks. At $n=5000$, induced-subgraph
mean KL is about $0.06502$ in CHILD and $0.18925$ in ALARM.
At $n=100$, CHILD's lower-dimensional induced subgraph can have
smaller joint KL than the exact conditional graphs because of the
bias--variance trade-off. We therefore do not claim that exact
representation guarantees superior finite-sample prediction for every
query or sample size.

\subsection{Numerical Behavior of the Certificates}
\label{subsec:bound-experiment}
We evaluate the original worst-cell theorem, the oracle-weighted
certificate, and the fully empirical certificate at $\delta=0.05$.
For a matched comparison, oracle and empirical weighted bounds share
the same local-CPT failure budget $\delta/2$.
The worst-cell theorem's assumptions fail in every tested fit:
published zero probabilities and rare parent cells cannot be ignored
when checking positivity and effective-count conditions.
We label these bounds \emph{not applicable}, rather than plotting an
unjustified numerical value.

Across all sizes, the study contains 300 CHILD and 3000 ALARM
distinct-graph/repetition fits. Neither weighted bound is violated.
These are correlated observations across candidate graphs and
nested sample sizes, not 3300 independent coverage trials.
Zero observed violations therefore does not establish exact 95\%
coverage. The bounds are very conservative: at $n=5000$, median
empirical upper bounds are approximately $14.31$ and $49.59$,
compared with median actual KL approximately $0.02261$ and $0.03857$.
This supports validity as a conservative certificate in these cases,
not practical tightness. Pooling rare cells, hierarchical priors,
or truncation may improve estimation but alter the model or estimator
and require separate analysis. No improvement for those procedures
is claimed from this experiment.

\subsection{Reproducibility and Remaining Scope}
\label{subsec:reproducibility}
The directory \texttt{reproducibility\_round2} contains the original BIF
files, explicit CPTs, saved orders, conditional samples, raw fit-level
losses, selection decisions, ten-repeat timings, configuration,
unit checks, figure-generation code, and environment metadata.
Running \texttt{test\_core.py}, \texttt{run\_experiments.py}, and
\texttt{make\_outputs.py} regenerates the new numerical evidence.
No network connection is required after obtaining this directory.
Numerical values are deterministic up to platform floating-point
differences; wall-clock timings are not.

This study uses only two fixed network parameterizations, one
conditioning event and one target query per network, 100 nonuniformly
sampled orders, and 20 repetitions. It is not a replication of the
previous unprovided random-parameter ALARM study, a large-network
scalability benchmark, or an empirical ROS comparison. Those earlier
results are excluded from the present evidential claims.

\paragraph{Causal scope.}
The experiment above concerns observational conditioning.
If a fully observed causal DAG and its mechanisms are already given,
a hard intervention on a set $J$ removes incoming arcs to $J$,
fixes $X_J$, and substitutes those values into child kernels.
FGCR can then be applied to the resulting known DAG and observation
event. A specified soft intervention replaces the relevant kernels,
with its parent structure declared and acyclic. These are representation
operations on a supplied post-intervention model, not solutions to
identification from observational data. Unknown interventions,
unobserved confounding, and marginalization over latent variables are
outside the theorem's fully observed DAG setting. We have removed the
earlier unreproduced intervention plot rather than treating it as
evidence for causal identification.
