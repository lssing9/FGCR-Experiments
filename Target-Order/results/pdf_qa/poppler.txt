                                           Abstract
    Conditioning can activate collider paths, so deleting conditioned vertices from a Bayesian
    network need not produce an independence map of the conditional model. We study
    Full-Graph Construct-and-Restrict (FGCR): a partition-preserving target order places
    conditioned vertices first, covered-arc transformations construct the full ordered minimal
    directed independence map, and restriction yields the corresponding conditional map. The
    conditional graph agrees with ROS under the same remaining-node order; the contribution
    is a construction and analysis framework, not a new graph object or uniform speed improve-
    ment. We give explicit partition-preserving correctness and restriction proofs, characterize
    minimal fill-in, and separate exact representation from finite-sample estimation. Beyond
    a uniform worst-cell bound, we derive a computable probability-weighted KL certificate
    using simultaneous confidence sets for parent-cell masses, and a held-out order-selection
    oracle inequality. New reproducible experiments use published CHILD and ALARM CPTs,
    100 randomized topological orders per network, and 20 paired repetitions. They verify
    structure and exact query agreement, show that simple dimension minimization can match
    or outperform pilot and validation selection, and quantify the substantial conservatism of
    the certificates. Data, saved samples, raw outputs, and executable code accompany the
    study.
    Keywords: Bayesian networks; conditioning; minimal directed independence map; target
    order; conditional inference


1. Introduction
1.1 Motivation and Problem Statement
A Bayesian network (BN) uses a directed acyclic graph (DAG) to encode conditional
independences and to factorize a joint distribution into local conditional distributions (Pearl,
1988; Koller and Friedman, 2009; Neapolitan, 2004). This representation combines statistical
interpretability with computational tractability and has become fundamental to causal

inference, structure learning, machine learning, and expert systems (Pearl, 2009; Drton and
Maathuis, 2017; Heinze-Deml et al., 2018; Yu et al., 2019; Vila-Francés et al., 2013).
    Many applications concern a selected subpopulation rather than the full population.
Medical data may include only hospitalized or symptomatic patients, surveys may cover
only respondents, and clinical decision systems routinely evaluate disease risks conditional
on demographic characteristics and medical history. Such tasks involve the conditional
distribution of the remaining variables XR given XC = xC , rather than the original joint
distribution.
    Conditioning can change the dependence structure among the remaining variables. In
the collider X → Z ← Y , for example, the path between X and Y is blocked unless Z or one
of its descendants is conditioned on; once this occurs, the path becomes active and induces
dependence (Pearl, 1988). Thus, the induced subgraph GR = G[R] obtained by deleting the
conditioned nodes can assert independences that do not hold in the conditional model: in
general, I(G)C ⊆ I(GR ). Direct restriction is valid only under conditioning closure, namely
when I(G)C = I(GR ) (Xie et al., 2025). Otherwise, one must construct a DAG on R that
captures every required dependence without retaining redundant edges. We formulate this
target as a minimal directed independence map (MDI map) of the conditional independence
model relative to a prescribed node ordering.

1.2 Target-Order Approach
Xie et al. (2025) proposed Reverse Order Search (ROS), which starts from the original
induced subgraph GR and progressively identifies the minimal fill-in edges required for
conditioning within the ancestral region relative to the conditioning set (Xie et al., 2025).
This paper addresses the same structural construction problem from the perspective of target
order: rather than directly searching for fill-in edges on GR , we first encode the conditioning
requirements into a target order on the full node set, and then obtain the conditional model
structure via the ordered MDI map construction of the full DAG.
    The motivation for FGCR is algorithmic as well as conceptual. ROS is local: it identifies
conditioning-related ancestral configurations and explicitly searches for the fill-in edges
that they induce. FGCR instead reuses a general full-DAG transformation primitive
(covering followed by covered-arc reversal) and represents conditioning by an order constraint.
This allows an implementation to reuse order-transformation data structures, provides the
invariant that the current graph is consistent with the current order, and makes the work
easy to instrument at the level of swaps and parent-set updates. These advantages do not
imply that FGCR is uniformly faster: ROS can be preferable when the conditioning-related
ancestral region is very small, whereas FGCR is useful when an existing implementation
already supports full-DAG order transformations. We do not infer a strict speed superiority
criterion from implementation convenience.
    Specifically, given a topological order β of the original DAG G, we set αC = β|C and
αR = β|R , and construct the target order α = (αC , αR ), so that all conditioning nodes
precede the remaining nodes, while preserving within C and R their original relative order
from β.
    On the full node set, following the transformation mechanism of Peña’s (2011) Method
B2, we apply adjacent swaps together with the necessary covering and covered-arc reversals

1.3 Scope of Novelty
FGCR is an alternative construction and a unifying reduction, not a new conditional graph
or a uniformly superior replacement for ROS. Once the remaining-node order is fixed, the
two methods have identical output. Consequently, exact factorization, the KL decomposition,
and the statistical bounds below apply equally to ROS when the same CPT estimator is
used. The contribution is the partition-preserving full-graph construction, its correctness
argument without the general Method B2 initialization, and the connection between ordered
structure and statistical complexity. Order selection is available to either constructor; we do
not claim that it is exclusive to FGCR.

1.4 What Is and Is Not Established
The restriction theorem and partition-specific initialization are structural results. The new
empirical-weight certificate and held-out oracle inequality make statistical order comparison
explicit, but are constructor-independent once candidate graphs are available. No theorem
establishes that ROS cannot perform the same selection, or that FGCR is always faster
on a graph class. Those would be different claims requiring separate proofs and controlled
implementations.

1.5 Contributions, Scope, and Organization
This paper organizes its contributions into four parts.

order MDI map construction on the full graph. Given the original DAG G, the conditioning

2.1.3 Independence Models and Minimal I-maps
For a probability distribution P , define its conditional independence model as

        I(P ) = {⟨A, B | S⟩ : XA ⊥ XB | XS [P ], A, B, S ⊆ V are pairwise disjoint} .

Here, the triplet ⟨A, B | S⟩ indicates that the random vectors XA and XB are conditionally
independent given XS .

   Similarly, the independence model induced by a DAG G is defined as

   For a family of probability distributions P, define its common independence model as

Definition 1 (Independence Map) Let G be a DAG defined on the node set V , and let P
be a family of probability distributions on XV . If I(G) ⊆ I(P), equivalently, if I(G) ⊆ I(P )
for every P ∈ P, then G is called an independence map (I-map) of P.

    When P = {P } contains only a single probability distribution, the above condition
reduces to I(G) ⊆ I(P ). Thus, the basic requirement of an I-map is that the graph must
not encode conditional independence relations that do not hold in the distribution. The
graph may fail to represent some valid independence relations, but it must not incorrectly
assert through d-separation an independence relation that does not actually hold.

Definition 2 (Minimal Independence Map) Let a DAG G = (V, E) be an I-map of the
distribution family P. If for every edge e ∈ E, the graph G − e is no longer an I-map of P,
that is, I(G − e) ⊈ I(P), then G is called a minimal independence map (minimal I-map) of
P (Pearl, 1988).

   Thus, for a minimal I-map, deleting any edge produces at least one d-separation relation
that is not supported by the distribution model.
   It is important to distinguish “minimal” from “minimum.” The minimality of a minimal
I-map is edgewise: no single edge can be deleted, but this does not guarantee that the graph
has the globally minimum number of edges among all possible DAGs. Different node orders
may correspond to different minimal I-maps. These graphs all satisfy edgewise minimality,
but may differ in the number of edges and their parent-set structures. Since this paper
consistently uses DAGs as graphical representations of independence models, a minimal
I-map represented by a DAG will also be referred to as a minimal directed independence
map (MDI map). For a given node order, we further consider an MDI map that is consistent
with that order, as defined in the following sections.

2.1.4 Graphoid Axioms of Conditional Independence
Conditional independence relations satisfy a collection of basic algebraic properties that
form the foundation of Graphoid theory (Dawid, 1979; Pearl and Paz, 1987; Pearl, 1988), an
axiomatic system for describing conditional independence relations.
    The independence model I(G) defined by d-separation in a DAG is a standard example
of a Graphoid. Let A, B, C, D be pairwise disjoint subsets of nodes, and write I(A, B | C)
to mean that “XA and XB are conditionally independent given XC ” (where the comma
represents set union, as in B ∪ D). A Graphoid satisfies the following five core axioms:
    Symmetry
                               I(A, B | C) =⇒ I(B, A | C)

   Decomposition
                              I(A, B ∪ D | C) =⇒ I(A, D | C)
   Weak Union
                           I(A, B ∪ D | C) =⇒ I(A, B | C ∪ D)
   Contraction

                    I(A, B | C ∪ D) and I(A, D | C) =⇒ I(A, B ∪ D | C)

   Intersection

                  I(A, B | C ∪ D) and I(A, C | B ∪ D) =⇒ I(A, B ∪ C | D)

     For arbitrary probability distributions, strict positivity is a sufficient condition for
intersection; it is not an assumption needed for the graphical arguments in this paper. The
d-separation model I(G) satisfies intersection directly. Indeed, suppose A ⊥d B | D ∪ C and
A ⊥d C | D ∪ B, but an active path given D connects A to B ∪ C. Stop that path at its first
vertex in B ∪ C. Its internal vertices avoid both sets, and every collider has a descendant
in D. If the endpoint lies in B, the prefix is still active given D ∪ C; if it lies in C, it is
still active given D ∪ B. Either case contradicts a premise. Thus intersection holds. The
other graphoid axioms hold for d-separation as well. Conditioning an independence model
on a fixed set simply adds that set to each conditioning argument, so I(G)C inherits these
axioms. In particular, all uses of intersection in the structural proofs below are graphical
and do not presuppose a strictly positive fitted distribution.

2.2 Ordered MDI Maps
A key issue in Peña’s work on consensus DAG construction is how to obtain the corresponding
MDI map under a given node order. Let α be a total order on the node set V . If a DAG
H is an MDI map of an independence model M, and every directed edge u → v ∈ E(H)
satisfies u ≺α v, then H is said to be consistent with the node order α.

Definition 3 (MDI Map Relative to a Given Node Order) Let M be an indepen-
dence model defined on the node set V , and let α be a total order on V . If a DAG H is an
MDI map of M and is consistent with the node order α, then H is called the MDI map of
M relative to the node order α.

    When the independence model M is a graphoid, for every given node order α, there
exists a unique MDI map consistent with α (Pearl, 1988; Peña, 2011). In particular, when
M = I(G), we denote by Gα the MDI map of I(G) with respect to the target order α. For
a given DAG G and target order α, Peña proposed a DAG transformation method for a
prescribed target order, whose basic operations include adjacent node swaps, arc covering,
and covered-arc reversal. The corrected Method B2 first determines an initial node order
from the original DAG and the target order, and then processes nodes from right to left
according to the target order, progressively obtaining the MDI map under the target order
through local graph transformations. The full-graph construction in this paper adopts
the above covering and covered-arc reversal mechanisms, while the target order is induced

2.4 Conditioning, Collapsibility, and ROS
The structural representation of Bayesian networks after conditioning has been studied
extensively. Since marginalization and conditioning may make the class of DAGs no longer
closed under structural representation, one line of research uses undirected graphs or more
general mixed graphs to represent the conditional independence structures induced by
these operations. Relevant representations include undirected and moral graphs (Lauritzen,
1996), summary graphs (Cox and Wermuth, 1996), MC graphs (Koster, 2002), ancestral
graphs (Richardson and Spirtes, 2002), and chain mixed graphs for representing structures
after marginalization and conditioning (Sadeghi, 2016). These graphical models provide
considerable flexibility in structural representation, but they generally involve undirected
edges, bidirected edges, or multiple edge types, and their probabilistic parameterizations
and local conditional factorizations are less direct than those of DAGs. Therefore, when
the objective is not only to describe conditional independence relations but also to perform
parameter estimation and conditional probabilistic inference, continuing to use a DAG
representation offers practical advantages.
    Within the DAG framework, Xie et al. (Xie et al., 2025) systematically studied con-
ditioning in Bayesian networks. Given an original DAG G = (V, E), a conditioning set
C ⊂ V , and the remaining-node set R = V \ C, they analyzed conditions under which
the original induced subgraph GR = G[R] continues to represent the conditional model.
When conditioning closure does not hold, appropriate directed edges must be added to GR
to construct a DAG MDI map of the conditional model. To this end, Xie et al. defined
a minimal fill-in edge set and, under faithfulness, established a correspondence between
minimal fill-in edge sets and MDI maps of the conditional distribution model.
    On this basis, Xie et al. proposed the Reverse Order Search (ROS) algorithm for
constructing minimal fill-in edge sets. ROS processes local structures within the ancestral
region associated with the conditioning set in the reverse order of a given topological
order and progressively adds the required fill-in edges. If the relevant region contains k
nodes and the maximum        parent-set size is m, the upper bound on its time complexity
is O m2 max{k − 2, 0} , so ROS can achieve relatively low computational complexity for
                        

sparse DAGs with small local parent sets.
    The above approach starts from the original induced subgraph GR and constructs the
conditional model by explicitly searching for fill-in edges required by conditioning. This
paper studies the same structural construction problem from the perspective of target-order
transformation. The conditioning requirement is converted into a node-order constraint on
the full DAG, and the conditional-model structure is obtained using the construction of an
MDI map under a given node order. We later prove a strict correspondence between this
construction and the minimal fill-in representation, and further analyze its relationship with
the output of ROS.

3.2 Why the Induced Subgraph Fails
Given a conditioning set C ⊂ V , let R = V \ C, and let GR = G[R] denote the subgraph of
the original graph induced by the remaining-node set. Since GR retains all directed edges
of the original graph whose endpoints both belong to R, it is the most direct candidate
structure for the conditional model.
    However, in general, I(G)C ⊆ I(GR ), and the inclusion may be strict. This occurs
because conditioning may activate paths containing colliders. For example, for the structure
x → w ← y, if w ∈ AnG (C), then conditioning on C may activate this path and induce
dependence between x and y in the conditional model, whereas the induced subgraph GR
obtained by removing the conditioning nodes does not automatically represent this change.
Therefore, when I(G)C ⊊ I(GR ), the graph GR encodes conditional independence relations
that do not hold in the conditional model.
    Xie, Guo, and Sun systematically studied closure of Bayesian networks under conditioning
in Section 4, “Closure of Bayesian Network under Conditioning.” If I(G)C = I(GR ), then
the graphical independence model is closed under conditioning. This is an equality of
independence models, not by itself an assertion that two arbitrary parameterized distribution
families are equal.
    An important special case is a root set: if no arc enters C from R, then I(G)C = I(GR ),
as proved in Lemma 12. For unrestricted discrete CPTs, equality of the corresponding
conditional distribution families also follows: conditioning fixes the C arguments in the
CPTs on R; conversely, any CPTs on GR can be extended to G by ignoring the C arguments
and choosing independent positive CPTs on C.
    This property provides the basis for the reduction used in this paper. For a general
conditioning set C, the original graph G need not be closed under conditioning on C. If
G can be transformed into an appropriate DAG H in which C forms a root set, then the
conditional model can be represented by H[R]. The next subsection realizes this construction
through a target node order.

3.3 Ordered MDI Map and Target-Order Reduction
Let B = (G, P(G)) be a Bayesian network, where G = (V, E) is a DAG. Given a conditioning
set C ⊂ V , let R = V \ C. This paper focuses on constructing an MDI map of the conditional
independence model I(G)C on the remaining-node set R. Specifically, given a node order
αR on R, the goal is to construct a DAG HR that is consistent with αR and is the MDI
map of I(G)C with respect to αR . Under the conditional-faithfulness witness condition,
Proposition 9 implies that this structure can also serve as a minimal directed representation
of the conditional distribution model P(G)C .
     Section 3.2 shows that, for a general conditioning set, the original induced subgraph
GR = G[R] need not represent all dependencies induced by conditioning. However, when the
conditioning set forms a root set in the DAG, conditioning is closed. This observation suggests
first changing the directed representation on the full node set V so that the conditioning set
becomes a root set, and then obtaining the conditional-model structure by restricting the
resulting graph to R.
     The key to the full-graph reduction is the choice of the target order. Given a topological
order β of G, we preserve the relative order of nodes within the conditioning set C and


                                              12
                     MDI Maps of Conditioned Bayesian Networks




within the remaining-node set R, and move all conditioning nodes before all remaining
nodes, obtaining α = (β|C , β|R ). This construction preserves the order information of the
original topological order within each of the two node sets, while encoding the conditioning
requirement as an ordering constraint between the two sets, thereby providing the basis for
the subsequent full-graph transformation and restriction.
    Let β = (v1 , v2 , . . . , v|V | ) be a topological order of the original DAG G. Preserving the
relative order of nodes in C and R as they appear in β, define αC = β|C , αR = β|R , and
construct the target order α = (αC , αR ). Thus, for any c ∈ C and r ∈ R, we have c ≺α r.
Moreover, αR remains a topological order of the original induced subgraph GR .
    Let H = Gα denote the MDI map of the independence model I(G) with respect to the
target order α. Since H is consistent with α, every directed edge entering a conditioning
node must originate within C, and hence C forms a root set in H. By closure under root-set
conditioning, I(H)C = I(HR ), so the target-order transformation on the full graph provides
a natural intermediate representation for constructing the conditional-model structure.
    We further establish the reduction HR = (Gα )[R], where HR is the MDI map of I(G)C
with respect to αR .
    Thus, the target-order MDI-map construction of the conditional model on the remaining-
node set can be carried out by first constructing Gα on the full node set V and then
restricting it to R. Consequently, the structural construction problem originally defined on
the conditional independence model I(G)C is reduced to constructing the MDI map of the
full DAG G with respect to a prescribed target order.
    The next section presents the computational implementation of this full-graph target-
order transformation; Section 5 further proves the correctness of the reduction, including
the I-map property and edgewise minimality of HR with respect to I(G)C .

4. Target-Order Reduction and FGCR
Section 3 reduces the structural construction problem of the conditional model to constructing
a target-order MDI map on the full node set. This section presents a concrete algorithmic
implementation of this reduction. The basic idea is as follows: starting from a topological
order of the original DAG, we first construct the target order α = (αC , αR ), in which all
conditioning nodes precede all remaining nodes. We then progressively transform the original
DAG G into the MDI map Gα with respect to the target order α through adjacent node
swaps, arc covering, and covered-arc reversals, and finally take the induced subgraph on the
remaining-node set.

4.2 Full-Graph Transformation
Given the original topological order β and the target order α = (αC , αR ) obtained from
Algorithm 1, the algorithm directly uses β as the initial node order and progressively
transforms the current order into α by swapping adjacent inverted pairs. Whenever a swap
requires changing the direction of a directed arc in the current DAG, the algorithm first
covers the arc and then performs a covered-arc reversal, thereby ensuring that the graph
remains a DAG throughout the transformation.
    Let the initial working order and graph be β0 = β, G0 = G, respectively. The algorithm
processes nodes from right to left according to the target order α. Let Y be the node currently
being processed, and let Z be the right neighbor of Y in the current working order βj . If Z
lies to the left of Y in the target order α, that is, if Z ≺α Y , then the relative positions of
Y and Z in the current order disagree with the target order, and the two nodes must be
swapped.
    Since the current graph Gi is consistent with the current working order βj , if a directed
arc exists between Y and Z, its direction can only be Y → Z. After Y and Z are swapped,
the corresponding direction should become Z → Y . However, an arbitrary arc reversal may
introduce directed cycles or alter the independence relations encoded by the graph, so the
reversal cannot be performed directly.
    Let PY = paGi (Y ), PZ = paGi (Z) \ {Y }. To make Y → Z a covered arc, we need
PY = PZ . Therefore, the parent-completion arcs that must be added are AGi (Y, Z) = {X →
Z : X ∈ PY \ PZ } ∪ {X → Y : X ∈ PZ \ PY }. After these parent-completion arcs are added,
pa(Z) = pa(Y ) ∪ {Y }, so Y → Z becomes a covered arc and can be reversed to Z → Y .
The positions of Y and Z are then swapped in the current working order, yielding the next
order βj+1 .
    If Y → Z does not exist in the current graph, no graph modification is required; only
the positions of the two adjacent nodes in the working order are swapped.

4.3 Complexity Analysis
Let p = |V |, e = |E|, let S denote the number of adjacent swaps required to transform
the initial order β into the target order α, let K denote the number of swaps that trigger
covered-arc reversals, and let ∆H denote the maximum in-degree over all intermediate DAGs
generated during the execution. Assume expected constant-time hash-set membership and
insertion; adjacency sets are used to store parent sets and that a position map is maintained
for the nodes in the current order.

Theorem 10 (Time Complexity) If the initial topological order β must be computed from
G, then the overall time complexity of Algorithm 1, Algorithm 2, and the final construction
HR = H[R] is O(p + e + S + K∆H ).

Proof Algorithm 1 scans β once to construct αC = β|C , αR = β|R , α = (αC , αR ),

    After Algorithm 2 obtains the full graph H = Gα , constructing HR = H[R] requires

    Therefore, the total time complexity of the complete FGCR procedure is
O(p + e + S + K∆H ).


    By the cross-partition swap property, every actual swap occurs between one node
in R and one node in C, and each pair of nodes is swapped at most once. Therefore,
S ≤ |C||R| = |C|(p − |C|). Moreover, K ≤ S, ∆H ≤ p − 1. Together with e = O(p2 ), this
gives the worst-case complexity TFGCR = O(p3 ).

sparse, and the maximum in-degree ∆H is bounded, we have S = O(p), K = O(p), e = O(p),
and the overall complexity becomes O(p), that is, approximately linear in the size of the
input graph.
    The ROS bound is the local-search bound reported by Xie et al. (2025); common input
reading and output materialization must also be counted in an end-to-end implementation.
Its k, m and FGCR’s S, K, ∆H measure different operations. Comparing these upper bounds
cannot prove a strict runtime ranking. We make no claim of a graph class on which FGCR
is always strictly faster. A fair empirical comparison fixes (G, C, αR ), records operation
counts and memory, and measures both implementations under the same runtime and data
structures.

5.2 Conditional-Graph I-Map and Minimality
The full-graph stage of FGCR produces H = Gα , where α = (αC , αR ) places all conditioning
nodes before the remaining nodes. This section establishes the central property of this
full-graph reduction: after restricting H to the remaining-node set R, the resulting induced
subgraph HR = H[R] is the MDI map of the conditional independence model I(G)C with
respect to the order αR . The proof proceeds in two steps. We first show that HR is an
I-map of I(G)C , and then establish its edgewise minimality with respect to αR .

5.2.1 I-map Property
Lemma 12 (Conditioning on a Root Set) Let H be a DAG, let C have no parents
outside C, and set R = V \ C. Then I(H[R]) = I(H)C .

Proof Fix disjoint A, B, S ⊆ R. Any path with endpoints in R that visits C has a
boundary edge c → r, with c ∈ C, r ∈ R. The vertex c is internal and is a non-collider
on this path because one incident edge has its tail at c. Conditioning on C blocks the
path. Thus an active path given S ∪ C must stay entirely in R. No vertex of R can have a
descendant in C, since such a directed path would contain an arc entering C from outside.
Moreover, any directed path between vertices of R stays in R. Hence a collider on an
R-path has a descendant in S ∪ C in H exactly when it has a descendant in S in H[R]. The
non-collider conditions also coincide. Active paths between A and B therefore coincide in
the two problems, which proves the equality.



Theorem 13 (I-map Property of the Conditional Model) Let G = (V, E) be a

be the MDI map of I(G) with respect to the target order α, and let HR = H[R]. Then
I(HR ) ⊆ I(G)C , that is, HR is an I-map of the conditional independence model I(G)C .
    Furthermore, for every P C ∈ P(G)C , I(HR ) ⊆ I(P C ), so HR is also an I-map of the
conditional distribution model P(G)C .

Proof Since H = Gα is an I-map of I(G), we have I(H) ⊆ I(G). By the definition of
conditioning of an independence model, this inclusion further implies I(H)C ⊆ I(G)C .
Since C forms a root set in H, Lemma 12 gives I(HR ) = I(H)C . Therefore,
I(HR ) = I(H)C ⊆ I(G)C , so HR is an I-map of the conditional independence model
I(G)C . Furthermore, Proposition 9 gives, without faithfulness, I(G)C ⊆ I(P C ) for every

P C ∈ P(G)C . Combining the above inclusions, I(HR ) ⊆ I(G)C ⊆ I(P C ), ∀P C ∈ P(G)C .

5.2.2 Edgewise Minimality
The preceding subsection establishes that HR is an I-map of the conditional independence
model I(G)C . To further show that HR is the MDI map with respect to the order αR , it
remains to prove that no directed edge in HR can be deleted.
    Since H = Gα is the MDI map of I(G) with respect to the order α, its parent sets are

5.4 Structural Equivalence with ROS
The preceding section shows that the FGCR output can be interpreted either as the MDI
map of the conditional independence model I(G)C with respect to αR , or as the graph
obtained by adding a minimal fill-in edge set to the original induced subgraph GR . This
allows FGCR to be compared with the ROS algorithm proposed by Xie et al. in terms of
the same theoretical object.
    The construction procedures of the two methods are different. FGCR starts from the full
DAG, first constructs a target order in which all conditioning nodes precede the remaining
nodes, then obtains the full-graph target-order MDI map through covered-arc reversals, and
finally takes its induced subgraph on the remaining-node set R.
    ROS instead focuses directly on local structural changes induced by conditioning. Within
the ancestral region associated with the conditioning set, it processes collider structures in
the reverse order of a given topological order and identifies the fill-in edges that must be
added to GR . Adding these fill-in edges to the induced subgraph GR produces the required
minimal independence map.
    Thus, the two methods differ essentially in their intermediate operations: the core
operations of FGCR are target-order adjustment and covered-arc reversal, whereas those of
ROS are reverse-order search over conditioning-related collider structures and connections
among parent nodes. We next show that despite these different construction procedures, the
two methods produce exactly the same minimal independence map when they use the same
remaining-node order.
    First, I(G)C is still a Graphoid on the remaining-node set R. Indeed, I(G) satisfies the
Graphoid properties of symmetry, decomposition, weak union, contraction, and intersection.

6.6 Target Orders and Finite-Sample Efficiency
The preceding section fixes a conditional-model MDI map HR and analyzes its probabilistic
representation, local parameter estimation, and overall finite-sample error. We now examine
the effects of varying the target order. In FGCR, the remaining-node order αR determines the
MDI map of the conditional independence model I(G)C relative to that order. Conditional
graphs obtained from different admissible target orders retain the corresponding MDI-map
property and, under the relevant probabilistic conditions, factorize the true conditional
distribution exactly, but their parent structures and parameter complexities may differ.
Accordingly, this section studies the effect of the target order from three perspectives: the
family of conditional graphs, structural complexity, and finite-sample error.

CHILD has 20 nodes and 25 arcs; ALARM has 37 nodes and 46 arcs. We retain one supplied

    For CHILD we condition on ChestXray = Normal and HypoxiaInO2 = Mild. The

describe the candidate set.

7.4 Empirical Summary
The directory reproducibility_round2 contains the original BIF files, explicit CPTs,
saved orders, conditional samples, raw fit-level losses, selection decisions, ten-repeat timings,
configuration, unit checks, figure-generation code, and environment metadata. Running
test_core.py, run_experiments.py, and make_outputs.py regenerates the new numerical

are deterministic up to platform floating-point differences; wall-clock timings are not.
    This study uses only two fixed network parameterizations, one conditioning event and
one target query per network, 100 nonuniformly sampled orders, and 20 repetitions. It is not
a replication of the previous unprovided random-parameter ALARM study, a large-network
scalability benchmark, or an empirical ROS comparison. Those earlier results are excluded
from the present evidential claims.
Causal scope. The experiment above concerns observational conditioning. If a fully
observed causal DAG and its mechanisms are already given, a hard intervention on a set J
removes incoming arcs to J, fixes XJ , and substitutes those values into child kernels. FGCR
can then be applied to the resulting known DAG and observation event. A specified soft
intervention replaces the relevant kernels, with its parent structure declared and acyclic.
These are representation operations on a supplied post-intervention model, not solutions
to identification from observational data. Unknown interventions, unobserved confounding,

8. Discussion
8.1 Relation to ROS and Peña’s Method B2
FGCR and ROS produce the same conditional graph for the same original DAG, conditioning
set, and remaining-node order. FGCR therefore should be read as a full-graph target-order
reduction and implementation framework, not as a new conditional graph or a uniformly
faster algorithm. Peña’s active-route framework motivates the proof strategy, while the
present partition-preserving initialization and the explicit descendant-set argument are
specialized to this construction.

8.2 Limitations
The empirical study uses two released networks, one supplied parameterization per network,
one evidence event and one query per network, 100 nonuniformly sampled topological orders,
and 20 paired repetitions. The confidence bounds are valid but conservative. The pilot
heuristic and validation selector do not uniformly improve on minimum dimension. The
experiment does not establish a speed ranking against an independently implemented ROS
system or a general statistical ranking of order selectors.

8.3 Reproducibility and Evidence Boundary
All numerical claims in the present revision are generated by the released code and saved
inputs in reproducibility_round2. The earlier unreleased historical experiment package
is not used as evidence here. Wall-clock timings are machine-dependent, and the random
Kahn procedure is not uniform over all topological orders.

8.4 Future Work
Future work includes tighter rare-cell bounds, hierarchical or pooled estimators, larger
and more diverse network families, graph uncertainty, equivalent-effort ROS benchmarking,
and target-order search with explicit validation control. Multiple and soft interventions,
latent-variable models, mixed and continuous variables require separate extensions.

8.5 Causal Scope
For a supplied fully observed causal DAG and supplied mechanisms, FGCR can be applied
after a specified hard or soft intervention has produced an acyclic post-intervention model.
This is a representation operation, not identification from observational data. Unknown
interventions, latent confounding, and marginalization are outside the present results.

9. Conclusion
This paper provides a structurally organized analysis of FGCR, a partition-preserving
target-order construction for conditional Bayesian network models. The conditional graph
is the ordered MDI map obtained by restriction of the transformed full graph, and it is
structurally equivalent to ROS under the same order. The separate statistical analysis
establishes exact factorization, decomposes KL error, and supplies both worst-cell and
computable probability-weighted bounds together with a validation-based order-selection
guarantee.
    The released CHILD and ALARM experiments verify the implementation, quantify
order-dependent complexity, and show both the usefulness and conservatism of the new
bounds. They also show why the paper does not claim universal superiority of FGCR
or any one order-selection heuristic. The main contribution is a transparent target-order
framework whose structural and statistical consequences can be reproduced and evaluated
independently.

Appendix A. Proof of Target-Order Transformation
This appendix proves Theorem 11 using explicit active-route cases and Lemma 38; it does
not assume that arbitrary initial orders satisfy the general Method B2 theorem. The node
processing order, adjacent swap rules, and the covered-arc reversal operations of Algorithm 2
correspond to Peña’s Method B2, but the two differ in the construction of the initial node
ordering: Peña’s Method B2 first constructs a specific initial ordering from G and the target
order α, whereas our algorithm directly takes the given topological order β of the original
graph G as the initial ordering.
    The target order in this paper has the special form α = (β|C , β|R ). We first prove
that this target order enjoys a within-block relative order preservation property during the
execution of the algorithm, and then on this basis show that when the algorithm directly
starts from β as the initial order, it still yields an MDI map of G with respect to α. For
the edge-addition part of the proof we adopt Peña’s active-route inductive framework from
Theorem 5, where the parts that originally relied on the specially constructed initial order
will be re-established using our partition-preservation property.
Proof dependencies and independent steps. The appendix uses four standard graph-
ical facts with their usual finite-DAG conditions: covered-arc reversal preserves Markov
equivalence (Lemma 6); ordered I-maps of graphoids have unique minimal predecessor
boundaries; d-separation equals separation in the moralized ancestral graph; and active
paths can be represented by routes whose internal colliders themselves lie in the conditioning
set. These are background facts, not new results (Pearl, 1988; Chickering, 1995; Peña, 2011).

                                         Li and Sun




The route criterion permits repeated vertices, requires endpoints outside the conditioning
set, and tests each internal occurrence separately.
    Peña supplies the historical active-route induction strategy, not an initialization theorem
being silently applied to an arbitrary order. The partition invariant, termination argument,
ancestral-maximum lemma, all edge-addition cases, and final equality argument are given
explicitly below. In particular, the key descendant-set fact is proved in Lemma 38, not
merely imported by its former external lemma number. Graphical intersection is proved in

A.1 Basic Properties of the Partition-Preserving Target Order
Lemma 34 (Relative Order Invariance) Let G = (V, E) be a DAG, V = C ∪R,             ˙    and let
β be a topological order of G. Construct the target order α = (β|C , β|R ) = (αC , αR ). Denote
by βj the current node order after the j-th adjacent swap performed by the algorithm, and
set β0 = β. Then for every j ≥ 0, βj |C = αC and βj |R = αR . That is, during the execution
of the algorithm, the relative order of nodes within C and within R never changes.
Proof We proceed by induction on the number of swaps j.
    For j = 0, by the definition of the target order α = (β0 |C , β0 |R ), we immediately have
β0 |C = αC and β0 |R = αR .
    Assume the claim holds for βj . Consider the next adjacent swap performed by the
algorithm. Let Y be the current node being processed and Z its right neighbour in βj .
According to the algorithm’s swap condition, Y and Z are swapped only if Z lies to the left
of Y in the target order α.
    If Y, Z ∈ C, then by the induction hypothesis βj |C = αC ; hence their relative order in
βj and in α is the same, so the swap condition cannot be satisfied. Similarly, if Y, Z ∈ R,
then βj |R = αR , and they cannot be swapped either.
    Thus every effective adjacent swap in the algorithm occurs between one node in C and
one node in R, and therefore never alters the relative order of nodes within either partition.
Consequently, after the swap we still have βj+1 |C = αC and βj+1 |R = αR . By mathematical
induction, the claim holds for all j ≥ 0.


Corollary 35 (Cross-partition swap type) Under the conditions of Lemma 34, suppose
the algorithm swaps adjacent nodes Y, Z in the current order βj , where Y is to the left of Z,
and Z is to the left of Y in the target order α. Then necessarily Y ∈ R and Z ∈ C.
Proof By Lemma 34, two nodes both in C or both in R have the same relative order
in βj and in α, so they cannot form an inverted pair to be swapped. Hence Y and
Z must belong to different partitions. Since α = (αC , αR ) places all nodes of C be-
fore all nodes of R, while currently Y ≺βj Z and Z ≺α Y , we must have Y ∈ R and Z ∈ C.

Lemma 36 (Consistency of graph and current working order) During the execu-
tion of Algorithm 2, let Gi be the current graph after i graph modifications, and let βj be the
current working order after j adjacent swaps. Then for every actual state (Gi , βj ) occurring

Proof Initially G0 = G and β0 = β. Since β is a topological order of G, G0 is a DAG
consistent with β0 .
     We proceed by induction over the states occurring during the execution. Assume the
current state is (Gi , βj ), and Gi is a DAG consistent with βj . Let the final state be (GT , βm ).
Let Y, Z be the adjacent nodes currently to be adjusted, and write Py = paGi (y) and
Pz = paGi (z) \ {y}. Specifically, Algorithm 2 constructs Gi+1 from Gi in one of three ways:
(i) reversing the covered arc Y → Z; (ii) adding an edge X → Z for some X ∈ Py \ Pz ; or
(iii) adding an edge X → Y for some X ∈ Pz \ Py .
     We show that for all 0 ≤ i ≤ T , Gi is a DAG consistent with the current order βj . Since
G0 satisfies the property, by induction it suffices, assuming the current state (Gi , βj ) with Gi
consistent with βj , to verify that each possible transition preserves the property. Consider
the following four cases.

covered arc cannot create any cycle, so Gi+1 is a DAG. Moreover, after the covered-arc
reversal, Y and Z are immediately swapped in βj . Hence Gi+1 is consistent with the new
working order.

consistent with βj , in βj we have X left of Y , and Y left of Z. Thus X is left of Z in βj ;
adding an edge consistent with the topological order cannot create a cycle, so Gi+1 is a
DAG consistent with βj .
     Case 3: Gi+1 is obtained by adding an edge X → Y with X ∈ Pz \ Py . Since Gi is

Lemma 38 (Ancestral Maximum of a Descendant Set) Let F, J be DAGs with
I(J) ⊆ I(F ) and let U = {y} ∪ deF (y). There is a unique vertex d ∈ U with no strict
ancestor in U in J. Every vertex of U is a descendant of d in J or is d itself. Here
“maximal” means ancestrally maximal, not latest in a topological order.

Proof Existence follows from finiteness and acyclicity. Suppose two such vertices u, v
exist. They are incomparable by ancestry in J. Put S = paJ (u) ∪ paJ (v); maximality gives
S ∩ U = ∅. In the ancestral graph of {u, v} ∪ S in J, neither u nor v has a descendant:
a descendant ancestral to the other endpoint or to one of its parents would contradict
incomparability, and one ancestral to its own parent would create a cycle. Thus u is a sink
there. In its moral graph the only neighbors of u are its parents, which are in S. The
moral-ancestral separation criterion gives u ⊥J v | S. In F , directed paths from y to u and
v have a last common vertex; their suffixes form a collider-free path between u, v, entirely
in U . It is active given S, contradicting I(J) ⊆ I(F ). So the maximal vertex is unique.
Following ancestors within the finite partially ordered set U shows that every vertex has
that same maximal ancestor, proving the last assertion.



A.3 Correctness of the MDI Map
From the above proof, the final graph GT is a DAG consistent with the target order α. On
the other hand, each graph modification does not introduce any new separations; hence
I(Gi+1 ) ⊆ I(Gi ) for every step, and consequently I(GT ) ⊆ I(G0 ). Thus GT is an I-map of
the original graph G0 with respect to the target order α. Since I(G0 ) is a graphoid, the
MDI map Gα of G0 with respect to α exists and is unique. To prove GT = Gα , it remains
to show I(Gα ) ⊆ I(GT ).

                                             48
                     MDI Maps of Conditioned Bayesian Networks




    By the definition of the MDI map we have I(Gα ) ⊆ I(G0 ). Thus, by induction, it suffices
to prove that for every 0 ≤ i < T , if I(Gα ) ⊆ I(Gi ), then I(Gα ) ⊆ I(Gi+1 ). Equivalently,
we prove the contrapositive: if in Gi+1 there exists A ̸⊥Gi+1 B | S, i.e. there is an active
route between A and B with respect to S, then in Gα also A ̸⊥Gα B | S.
    We adopt Peña’s route terminology. A route is a finite sequence of adjacent nodes,
possibly with repetitions and possibly of length zero. Endpoints are outside the conditioning
set; collider tests concern only internal occurrences. The active-route criterion below is
equivalent to the usual active-path criterion: a path collider activated by a descendant in
the conditioning set can be replaced by a directed detour to that descendant and back.
Conversely, removal of repeated segments yields an active path with every collider ancestral
to the conditioning set. An S-active route is one in which every collider on the route belongs
to S, and every non-collider does not belong to S.
    First consider the case where Gi+1 is obtained from Gi by reversing a covered arc Y → Z.
Since the reversed edge is covered, we have I(Gi+1 ) = I(Gi ). Therefore I(Gα ) ⊆ I(Gi )
implies I(Gα ) ⊆ I(Gi+1 ).
    Now consider the edge-addition cases. We follow the two-layer inductive idea of Peña’s
Theorem 5 for edge additions. Assume I(Gα ) ⊆ I(Gi ), and prove that after adding one edge
we still have I(Gα ) ⊆ I(Gi+1 ). To this end, take any S-active route in Gi+1 connecting A, B,
and among all such routes choose one in which the newly added edge appears a minimal
number of times; denote it by ρAB  i+1 . We induct on the number of occurrences of the new
edge in that route. If the new edge appears zero times, the route already exists in Gi , so by
I(Gα ) ⊆ I(Gi ) there is a corresponding S-active route in Gα . If it appears k + 1 times, we
further distinguish the two types of added edges X → Z or X → Y , decompose the original
route into sub-routes containing at most k occurrences of the new edge, apply the induction
hypothesis to obtain the corresponding active sub-routes in Gα , and then use the adjacency
properties guaranteed by I(Gα ) ⊆ I(Gi ) and the orientations forced by the target order α
to concatenate them into an S-active route in Gα . Suppose the claim holds for routes in
which the new edge appears at most k times. We now detail the case of k + 1 occurrences.
Reverse the route if necessary so that the selected occurrence traverses the new arc from its

Appendix C. Independent Validation and Reproduction
C.1 Independent Small-Graph and Probability Checks
The released test_core.py enumerates every subset of the forward arcs under a fixed
labeled topological order for p = 1, . . . , 5, and every conditioning set, including the empty
and full sets. The number of input triples is 5p=1 2p(p−1)/2+p = 33866. Relabeling covers
                                                   P

any specified initial topological order. Full and conditional outputs are separately compared
to an independent ancestral-moralization d-separation oracle: all 67732 edge-set checks pass.
    The ordered oracle inserts u → v exactly when u ̸⊥d v | Preα (v) \ {u}[G], or the
corresponding statement with C added for the conditional graph. For a graphoid, weak
union proves the absence of non-parent edges in this test, and intersection would remove any
purported parent that satisfied this separation. Thus it implements the defining ordered
parent boundary, not the same covering algorithm under another name.
    Probability tests independently enumerate a four-variable joint table and compare 98
evidence/query cases with variable elimination, including permuted query-axis orders. The
direct joint KL agrees with the local decomposition to about 10−17 . Tests also check empty
fitted cells, all released CPT normalizations, and the bounded-simplex optimizer against a
grid of feasible weight vectors. These tests are finite implementation checks, not substitutes
for the general mathematical proofs.

C.2 Released Files and Commands
The accompanying directory contains:
• bn_core.py: parsing, graph operations, the independent oracle, factor operations, exact
  inference, sampling, CPT fitting, and confidence calculations;
• config.json: fixed seeds, evidence, targets, sample sizes, repetitions, prior mass, and
  timing settings;
• test_core.py and verify_saved.py: implementation tests and re-evaluation of saved
  evidence;
• run_experiments.py: the complete new experimental study;
• make_outputs.py: tables and vector figures generated only from saved results;

• data/: source networks, exact CPT arrays, all sampled orders, and split-ready accepted

• results/: raw losses, all timing repetitions, selections, aggregates, checksums, tests,

The README gives installation and execution commands. The core study requires NumPy;
the figure generator additionally uses ReportLab. The downloaded network files are bundled,
so rerunning the study is offline. With the recorded versions and seeds, graph and statistical
outputs should agree up to floating-point tolerances; elapsed times must not be expected to
reproduce exactly.

Appendix D. Reproducibility Package and Prespecified Extensions
The complete code and current inputs are stored under reproducibility_round2/. The
executable entry points are test_core.py, run_experiments.py, make_outputs.py,
verify_saved.py, and audit_pdf.py. The directory also contains the exact BIF files,
exported CPT arrays, all sampled orders, accepted conditional samples, raw per-fit outputs,
timing repetitions, generated vector figures, LaTeX tables, environment metadata, and
replay checks.
    The proposed extension protocol is intentionally separated from completed evidence.
Additional networks, broader parameter libraries, alternative rare-cell estimators, and
equivalent-effort ROS measurements should be added only with fixed seeds, released raw
outputs, and independent validation data. The package README records the commands
and the data split convention. No planned experiment is counted as a result of this revision.
