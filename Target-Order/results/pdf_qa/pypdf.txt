Abstract
Conditioning can activate collider paths, so deleting conditioned vertices from a Bayesian
network need not produce an independence map of the conditional model. We study
Full-Graph Construct-and-Restrict (FGCR): a partition-preserving target order places
conditioned vertices first, covered-arc transformations construct the full ordered minimal
directed independence map, and restriction yields the corresponding conditional map. The
conditional graph agrees with ROS under the same remaining-node order; the contribution
is a construction and analysis framework, not a new graph object or uniform speed improve-
ment. We give explicit partition-preserving correctness and restriction proofs, characterize
minimal fill-in, and separate exact representation from finite-sample estimation. Beyond
a uniform worst-cell bound, we derive a computable probability-weighted KL certificate
using simultaneous confidence sets for parent-cell masses, and a held-out order-selection
oracle inequality. New reproducible experiments use published CHILD and ALARM CPTs,
100 randomized topological orders per network, and 20 paired repetitions. They verify
structure and exact query agreement, show that simple dimension minimization can match
or outperform pilot and validation selection, and quantify the substantial conservatism of
the certificates. Data, saved samples, raw outputs, and executable code accompany the
study.
Keywords: Bayesian networks; conditioning; minimal directed independence map; target
order; conditional inference
1. Introduction
1.1 Motivation and Problem Statement
A Bayesian network (BN) uses a directed acyclic graph (DAG) to encode conditional
independences and to factorize a joint distribution into local conditional distributions (Pearl,
1988; Koller and Friedman, 2009; Neapolitan, 2004). This representation combines statistical
interpretability with computational tractability and has become fundamental to causal

inference, structure learning, machine learning, and expert systems (Pearl, 2009; Drton and
Maathuis, 2017; Heinze-Deml et al., 2018; Yu et al., 2019; Vila-Francés et al., 2013).
Many applications concern a selected subpopulation rather than the full population.
Medical data may include only hospitalized or symptomatic patients, surveys may cover
only respondents, and clinical decision systems routinely evaluate disease risks conditional
on demographic characteristics and medical history. Such tasks involve the conditional
distribution of the remaining variablesXR givenXC =xC, rather than the original joint
distribution.
Conditioning can change the dependence structure among the remaining variables. In
the colliderX→Z←Y, for example, the path betweenX andY is blocked unlessZ or one
of its descendants is conditioned on; once this occurs, the path becomes active and induces
dependence (Pearl, 1988). Thus, the induced subgraphGR =G[R] obtained by deleting the
conditioned nodes can assert independences that do not hold in the conditional model: in
general,I(G)C⊆I(GR). Direct restriction is valid only under conditioning closure, namely
whenI(G)C =I(GR) (Xie et al., 2025). Otherwise, one must construct a DAG onR that
captures every required dependence without retaining redundant edges. We formulate this
target as a minimal directed independence map (MDI map) of the conditional independence
model relative to a prescribed node ordering.
1.2 Target-Order Approach
Xie et al. (2025) proposed Reverse Order Search (ROS), which starts from the original
induced subgraph GR and progressively identifies the minimal fill-in edges required for
conditioning within the ancestral region relative to the conditioning set (Xie et al., 2025).
This paper addresses the same structural construction problem from the perspective of target
order: rather than directly searching for fill-in edges onGR, we first encode the conditioning
requirements into a target order on the full node set, and then obtain the conditional model
structure via the ordered MDI map construction of the full DAG.
The motivation for FGCR is algorithmic as well as conceptual. ROS is local: it identifies
conditioning-related ancestral configurations and explicitly searches for the fill-in edges
that they induce. FGCR instead reuses a general full-DAG transformation primitive
(covering followed by covered-arc reversal) and represents conditioning by an order constraint.
This allows an implementation to reuse order-transformation data structures, provides the
invariant that the current graph is consistent with the current order, and makes the work
easy to instrument at the level of swaps and parent-set updates. These advantages do not
imply that FGCR is uniformly faster: ROS can be preferable when the conditioning-related
ancestral region is very small, whereas FGCR is useful when an existing implementation
already supports full-DAG order transformations. We do not infer a strict speed superiority
criterion from implementation convenience.
Specifically, given a topological orderβof the original DAGG, we setαC =β|C and
αR = β|R, and construct the target orderα= (αC,αR), so that all conditioning nodes
precede the remaining nodes, while preserving withinC and R their original relative order
from β.
On the full node set, following the transformation mechanism of Peña’s (2011) Method
B2, we apply adjacent swaps together with the necessary covering and covered-arc reversals

1.3 Scope of Novelty
FGCR is an alternative construction and a unifying reduction, not a new conditional graph
or a uniformly superior replacement for ROS. Once the remaining-node order is fixed, the
two methods have identical output. Consequently, exact factorization, the KL decomposition,
and the statistical bounds below apply equally to ROS when the same CPT estimator is
used. The contribution is the partition-preserving full-graph construction, its correctness
argument without the general Method B2 initialization, and the connection between ordered
structure and statistical complexity. Order selection is available to either constructor; we do
not claim that it is exclusive to FGCR.
1.4 What Is and Is Not Established
The restriction theorem and partition-specific initialization are structural results. The new
empirical-weight certificate and held-out oracle inequality make statistical order comparison
explicit, but are constructor-independent once candidate graphs are available. No theorem
establishes that ROS cannot perform the same selection, or that FGCR is always faster
on a graph class. Those would be different claims requiring separate proofs and controlled
implementations.
1.5 Contributions, Scope, and Organization

Definition 1 (Independence Map)LetG be a DAG defined on the node setV, and letP
be a family of probability distributions onXV. IfI(G)⊆I(P), equivalently, ifI(G)⊆I(P )

WhenP ={P}contains only a single probability distribution, the above condition

not encode conditional independence relations that do not hold in the distribution. The
graph may fail to represent some valid independence relations, but it must not incorrectly
assert throughd-separation an independence relation that does not actually hold.
Definition 2 (Minimal Independence Map)Let a DAGG = (V,E ) be an I-map of the
distribution familyP. If for every edgee∈E, the graphG−e is no longer an I-map ofP,
that is,I(G−e) ⊈I(P), thenG is called a minimal independence map (minimal I-map) of
P (Pearl, 1988).
Thus, for a minimal I-map, deleting any edge produces at least oned-separation relation
that is not supported by the distribution model.
It is important to distinguish “minimal” from “minimum.” The minimality of a minimal
I-map is edgewise: no single edge can be deleted, but this does not guarantee that the graph
has the globally minimum number of edges among all possible DAGs. Different node orders
may correspond to different minimal I-maps. These graphs all satisfy edgewise minimality,
but may differ in the number of edges and their parent-set structures. Since this paper
consistently uses DAGs as graphical representations of independence models, a minimal
I-map represented by a DAG will also be referred to as a minimal directed independence
map (MDI map). For a given node order, we further consider an MDI map that is consistent
with that order, as defined in the following sections.
2.1.4 Graphoid Axioms of Conditional Independence
Conditional independence relations satisfy a collection of basic algebraic properties that
form the foundation of Graphoid theory (Dawid, 1979; Pearl and Paz, 1987; Pearl, 1988), an
axiomatic system for describing conditional independence relations.
The independence modelI(G) defined byd-separation in a DAG is a standard example
of a Graphoid. LetA,B,C,D be pairwise disjoint subsets of nodes, and writeI(A,B|C)
to mean that “XA and XB are conditionally independent givenXC” (where the comma
represents set union, as inB∪D). A Graphoid satisfies the following five core axioms:
Symmetry
I(A,B|C) =⇒I(B,A|C)

For arbitrary probability distributions, strict positivity is a sufficient condition for
intersection; it is not an assumption needed for the graphical arguments in this paper. The
d-separation modelI(G) satisfies intersection directly. Indeed, supposeA⊥dB|D∪C and
A⊥dC|D∪B, but an active path givenD connectsA toB∪C. Stop that path at its first
vertex inB∪C. Its internal vertices avoid both sets, and every collider has a descendant
in D. If the endpoint lies inB, the prefix is still active givenD∪C; if it lies inC, it is
still active givenD∪B. Either case contradicts a premise. Thus intersection holds. The
other graphoid axioms hold ford-separation as well. Conditioning an independence model
on a fixed set simply adds that set to each conditioning argument, soI(G)C inherits these
axioms. In particular, all uses of intersection in the structural proofs below are graphical
and do not presuppose a strictly positive fitted distribution.

2.4 Conditioning, Collapsibility, and ROS
The structural representation of Bayesian networks after conditioning has been studied
extensively. Since marginalization and conditioning may make the class of DAGs no longer
closed under structural representation, one line of research uses undirected graphs or more
general mixed graphs to represent the conditional independence structures induced by
these operations. Relevant representations include undirected and moral graphs (Lauritzen,
1996), summary graphs (Cox and Wermuth, 1996), MC graphs (Koster, 2002), ancestral
graphs (Richardson and Spirtes, 2002), and chain mixed graphs for representing structures
after marginalization and conditioning (Sadeghi, 2016). These graphical models provide
considerable flexibility in structural representation, but they generally involve undirected
edges, bidirected edges, or multiple edge types, and their probabilistic parameterizations
and local conditional factorizations are less direct than those of DAGs. Therefore, when
the objective is not only to describe conditional independence relations but also to perform
parameter estimation and conditional probabilistic inference, continuing to use a DAG
representation offers practical advantages.
Within the DAG framework, Xie et al. (Xie et al., 2025) systematically studied con-
ditioning in Bayesian networks. Given an original DAGG = (V,E ), a conditioning set
C⊂V, and the remaining-node setR = V\C, they analyzed conditions under which
the original induced subgraphGR = G[R] continues to represent the conditional model.
When conditioning closure does not hold, appropriate directed edges must be added toGR
to construct a DAG MDI map of the conditional model. To this end, Xie et al. defined
a minimal fill-in edge set and, under faithfulness, established a correspondence between
minimal fill-in edge sets and MDI maps of the conditional distribution model.
On this basis, Xie et al. proposed the Reverse Order Search (ROS) algorithm for
constructing minimal fill-in edge sets. ROS processes local structures within the ancestral
region associated with the conditioning set in the reverse order of a given topological
order and progressively adds the required fill-in edges. If the relevant region containsk
nodes and the maximum parent-set size ism, the upper bound on its time complexity
is O
(
m2 max{k−2, 0}
)
, so ROS can achieve relatively low computational complexity for
sparse DAGs with small local parent sets.
The above approach starts from the original induced subgraphGR and constructs the
conditional model by explicitly searching for fill-in edges required by conditioning. This
paper studies the same structural construction problem from the perspective of target-order
transformation. The conditioning requirement is converted into a node-order constraint on
the full DAG, and the conditional-model structure is obtained using the construction of an
MDI map under a given node order. We later prove a strict correspondence between this
construction and the minimal fill-in representation, and further analyze its relationship with
the output of ROS.

3.2 Why the Induced Subgraph Fails
Given a conditioning setC⊂V, letR =V\C, and letGR =G[R] denote the subgraph of
the original graph induced by the remaining-node set. SinceGR retains all directed edges
of the original graph whose endpoints both belong toR, it is the most direct candidate
structure for the conditional model.
However, in general,I(G)C ⊆I(GR), and the inclusion may be strict. This occurs
because conditioning may activate paths containing colliders. For example, for the structure
x→w←y, ifw∈AnG(C), then conditioning onC may activate this path and induce
dependence betweenx and y in the conditional model, whereas the induced subgraphGR
obtained by removing the conditioning nodes does not automatically represent this change.
Therefore, whenI(G)C ⊊I(GR), the graphGR encodes conditional independence relations
that do not hold in the conditional model.
Xie, Guo, and Sun systematically studied closure of Bayesian networks under conditioning
in Section 4, “Closure of Bayesian Network under Conditioning.” IfI(G)C =I(GR), then
the graphical independence model is closed under conditioning. This is an equality of
independence models, not by itself an assertion that two arbitrary parameterized distribution
families are equal.
An important special case is a root set: if no arc entersC from R, thenI(G)C =I(GR),
as proved in Lemma 12. For unrestricted discrete CPTs, equality of the corresponding
conditional distribution families also follows: conditioning fixes theC arguments in the
CPTs onR; conversely, any CPTs onGR can be extended toG by ignoring theC arguments
and choosing independent positive CPTs onC.
This property provides the basis for the reduction used in this paper. For a general
conditioning setC, the original graphG need not be closed under conditioning onC. If
G can be transformed into an appropriate DAGH in whichC forms a root set, then the
conditional model can be represented byH[R]. The next subsection realizes this construction
through a target node order.
3.3 Ordered MDI Map and Target-Order Reduction
LetB = (G,P(G)) be a Bayesian network, whereG = (V,E ) is a DAG. Given a conditioning
setC⊂V, letR =V\C. This paper focuses on constructing an MDI map of the conditional
independence modelI(G)C on the remaining-node setR. Specifically, given a node order
αR on R, the goal is to construct a DAGHR that is consistent withαR and is the MDI
map ofI(G)C with respect toαR. Under the conditional-faithfulness witness condition,
Proposition 9 implies that this structure can also serve as a minimal directed representation
of the conditional distribution modelP(G)C.
Section 3.2 shows that, for a general conditioning set, the original induced subgraph
GR =G[R] need not represent all dependencies induced by conditioning. However, when the
conditioning set forms a root set in the DAG, conditioning is closed. This observation suggests
first changing the directed representation on the full node setV so that the conditioning set
becomes a root set, and then obtaining the conditional-model structure by restricting the
resulting graph toR.
The key to the full-graph reduction is the choice of the target order. Given a topological
order βof G, we preserve the relative order of nodes within the conditioning setC and

5.4 Structural Equivalence with ROS
The preceding section shows that the FGCR output can be interpreted either as the MDI
map of the conditional independence modelI(G)C with respect toαR, or as the graph
obtained by adding a minimal fill-in edge set to the original induced subgraphGR. This
allows FGCR to be compared with the ROS algorithm proposed by Xie et al. in terms of
the same theoretical object.
The construction procedures of the two methods are different. FGCR starts from the full
DAG, first constructs a target order in which all conditioning nodes precede the remaining
nodes, then obtains the full-graph target-order MDI map through covered-arc reversals, and
finally takes its induced subgraph on the remaining-node setR.
ROS instead focuses directly on local structural changes induced by conditioning. Within
the ancestral region associated with the conditioning set, it processes collider structures in
the reverse order of a given topological order and identifies the fill-in edges that must be
added toGR. Adding these fill-in edges to the induced subgraphGR produces the required
minimal independence map.
Thus, the two methods differ essentially in their intermediate operations: the core
operations of FGCR are target-order adjustment and covered-arc reversal, whereas those of
ROS are reverse-order search over conditioning-related collider structures and connections
among parent nodes. We next show that despite these different construction procedures, the
two methods produce exactly the same minimal independence map when they use the same
remaining-node order.
First, I(G)C is still a Graphoid on the remaining-node setR. Indeed,I(G) satisfies the
Graphoid properties of symmetry, decomposition, weak union, contraction, and intersection.

6.6 Target Orders and Finite-Sample Efficiency

8. Discussion
8.1 Relation to ROS and Peña’s Method B2
FGCR and ROS produce the same conditional graph for the same original DAG, conditioning
set, and remaining-node order. FGCR therefore should be read as a full-graph target-order
reduction and implementation framework, not as a new conditional graph or a uniformly
faster algorithm. Peña’s active-route framework motivates the proof strategy, while the
present partition-preserving initialization and the explicit descendant-set argument are
specialized to this construction.
8.2 Limitations
The empirical study uses two released networks, one supplied parameterization per network,
one evidence event and one query per network, 100 nonuniformly sampled topological orders,
and 20 paired repetitions. The confidence bounds are valid but conservative. The pilot
heuristic and validation selector do not uniformly improve on minimum dimension. The
experiment does not establish a speed ranking against an independently implemented ROS
system or a general statistical ranking of order selectors.
8.3 Reproducibility and Evidence Boundary
All numerical claims in the present revision are generated by the released code and saved
inputs in reproducibility_round2. The earlier unreleased historical experiment package
is not used as evidence here. Wall-clock timings are machine-dependent, and the random
Kahn procedure is not uniform over all topological orders.
8.4 Future Work
Future work includes tighter rare-cell bounds, hierarchical or pooled estimators, larger
and more diverse network families, graph uncertainty, equivalent-effort ROS benchmarking,
and target-order search with explicit validation control. Multiple and soft interventions,
latent-variable models, mixed and continuous variables require separate extensions.
8.5 Causal Scope
For a supplied fully observed causal DAG and supplied mechanisms, FGCR can be applied
after a specified hard or soft intervention has produced an acyclic post-intervention model.
This is a representation operation, not identification from observational data. Unknown
interventions, latent confounding, and marginalization are outside the present results.

9. Conclusion
This paper provides a structurally organized analysis of FGCR, a partition-preserving
target-order construction for conditional Bayesian network models. The conditional graph
is the ordered MDI map obtained by restriction of the transformed full graph, and it is
structurally equivalent to ROS under the same order. The separate statistical analysis
establishes exact factorization, decomposes KL error, and supplies both worst-cell and
computable probability-weighted bounds together with a validation-based order-selection
guarantee.
The released CHILD and ALARM experiments verify the implementation, quantify
order-dependent complexity, and show both the usefulness and conservatism of the new
bounds. They also show why the paper does not claim universal superiority of FGCR
or any one order-selection heuristic. The main contribution is a transparent target-order
framework whose structural and statistical consequences can be reproduced and evaluated
independently.

Appendix A. Proof of Target-Order Transformation
This appendix proves Theorem 11 using explicit active-route cases and Lemma 38; it does
not assume that arbitrary initial orders satisfy the general Method B2 theorem. The node
processing order, adjacent swap rules, and the covered-arc reversal operations of Algorithm 2
correspond to Peña’s Method B2, but the two differ in the construction of the initial node
ordering: Peña’s Method B2 first constructs a specific initial ordering fromG and the target
order α, whereas our algorithm directly takes the given topological orderβof the original
graph G as the initial ordering.
The target order in this paper has the special formα= (β|C,β|R). We first prove
that this target order enjoys a within-block relative order preservation property during the
execution of the algorithm, and then on this basis show that when the algorithm directly
starts fromβas the initial order, it still yields an MDI map ofG with respect toα. For
the edge-addition part of the proof we adopt Peña’s active-route inductive framework from
Theorem 5, where the parts that originally relied on the specially constructed initial order
will be re-established using our partition-preservation property.
Proof dependencies and independent steps. The appendix uses four standard graph-

equivalence (Lemma 6); ordered I-maps of graphoids have unique minimal predecessor
boundaries; d-separation equals separation in the moralized ancestral graph; and active
paths can be represented by routes whose internal colliders themselves lie in the conditioning
set. These are background facts, not new results (Pearl, 1988; Chickering, 1995; Peña, 2011).

Proof We proceed by induction on the number of swapsj.

The released test_core.py enumerates every subset of the forward arcs under a fixed
labeled topological order forp = 1,..., 5, and every conditioning set, including the empty
and full sets. The number of input triples is∑5
p=1 2p(p−1)/2+p = 33866. Relabeling covers
any specified initial topological order. Full and conditional outputs are separately compared
to an independent ancestral-moralizationd-separation oracle: all 67732 edge-set checks pass.
The ordered oracle insertsu→v exactly when u̸⊥d v |Preα(v)\{u}[G], or the
corresponding statement withC added for the conditional graph. For a graphoid, weak
union proves the absence of non-parent edges in this test, and intersection would remove any
purported parent that satisfied this separation. Thus it implements the defining ordered
parent boundary, not the same covering algorithm under another name.
Probability tests independently enumerate a four-variable joint table and compare 98
evidence/query cases with variable elimination, including permuted query-axis orders. The
direct joint KL agrees with the local decomposition to about10−17. Tests also check empty
fitted cells, all released CPT normalizations, and the bounded-simplex optimizer against a
grid of feasible weight vectors. These tests are finite implementation checks, not substitutes
for the general mathematical proofs.
